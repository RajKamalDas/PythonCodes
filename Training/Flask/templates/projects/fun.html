Terminal Minesweeper

A keyboard-controlled Minesweeper game implemented entirely in Python. Features dynamic grid sizes, adjustable mine counts, marking mechanics, score calculation, and replay support.

This project wasn’t about polish—it was about understanding game state, user input, and logic flow without leaning on frameworks. Basically: building the thing from the ground up just to see if I could.
