Desktop Utilities

MassMover – Batch File Organizer

A desktop utility built with Python and Tkinter that moves files from one directory to another based on file type. It includes folder selection dialogs, extension filtering, automatic conflict resolution, and persistent configuration via .ini files.

Renamer – Bulk File Renaming Tool

A GUI-based batch renaming tool that renames files based on starting text or contained keywords. Designed to handle naming collisions gracefully and remember previous settings for repeat use.

These tools came from very real “I’m tired of doing this manually” moments—and that’s usually where my best ideas start. 😅
